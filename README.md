# منصة متابعة موظفي الارتباط (ASP.NET Core 8 + PostgreSQL)

## النشر على Render
1. ارفع هذا المجلد كاملاً إلى مستودع GitHub.
2. في Render: New ← Blueprint ← اختر المستودع (يقرأ render.yaml وينشئ الخدمة وقاعدة PostgreSQL).
3. عند الطلب أدخل قيمة ADMIN_PASSWORD (كلمة سر حساب admin).
4. بعد اكتمال البناء افتح الرابط وادخل بالمستخدم admin.
5. من "استيراد الفروع" الصق جدول الفروع، ثم من "المستخدمون" أنشئ حساباً لكل مندوب واربطه بمنطقته.

## التشغيل محلياً
dotnet run   (يحتاج PostgreSQL محلياً أو متغير DATABASE_URL)
